Transparency & Trust

Privacy Policy

Last updated: August 27, 2026. Tideway is engineered with a strict local-first privacy architecture. We believe your filesystem contents, directory hierarchies, and file names belong exclusively to you.

1. Local-First Processing & Filesystem Privacy

Tideway operates entirely on your host environment. When scanning, organizing, or monitoring folders, file paths and binary contents are never uploaded to remote cloud servers, external analytics trackers, or third parties.

  • No Remote Telemetry: Tideway does not collect usage analytics or device identifiers.
  • Local Audit Logs: Move operation logs (tideway/logs/run_*.log) reside exclusively in your local storage for 1-click rollbacks.

2. Cookies & Browser Storage

Tideway uses client-side browser storage (localStorage) solely for strictly essential user interface preferences:

Theme & UI State Dark mode settings, selected dashboard tabs, and filter preferences.
Cookie Consent Remembers your banner acknowledgment so you are not prompted repeatedly.

3. Third-Party CDNs & Assets

The dashboard interface utilizes trusted public CDNs for UI styling and charting libraries (Tailwind CSS, Lucide Icons, Chart.js). These requests are standard static asset fetches governed by the respective CDN privacy policies. No user data or directory metadata is included in asset requests.

4. User Rights & Control (GDPR / CCPA)

Because Tideway does not hold personal data on external servers, you retain 100% control over your data at all times:

  • Data Erasure: Deleting the tideway/logs/ folder instantly removes all transaction history.
  • Cookie Reset: Clearing your browser's site data or cache immediately wipes all stored preferences.

5. Open Source & Code Auditing

Tideway is fully open source under the MIT License. You can review every line of code, audit the API endpoints, and inspect background watcher routines directly on GitHub.
