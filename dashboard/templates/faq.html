Getting Started & General

What is Tideway and what problem does it solve?

Tideway is a modern, high-performance file organization engine built for chaotic folders (such as Downloads, Desktops, and project staging folders). It automatically categorizes files into clean, categorized directories (e.g., Images, Documents, Code & Web, Archives).

Unlike basic scripts, Tideway offers a real-time WebSocket dashboard, live move streaming, dry-run diff previews, continuous folder watchers, and 1-click transactional rollback.

How do I launch the Web Dashboard or use the CLI?

You can run Tideway in either Web Dashboard or Terminal CLI mode:

  • python main.py --dashboard — Launches the FastAPI Web Dashboard on http://localhost:8000.
  • python main.py — Opens the interactive Terminal menu.
  • python main.py --target "C:\path" --dry-run — Runs a quick preview from the command line.
Does Tideway ever permanently delete my files?

No. Tideway only moves files into designated category folders or renames duplicate filenames safely. It never deletes user files. During Deep Scans, only completely empty leftover directories are cleaned up to keep the tree tidy.

Safety, Previews & Rollback

How does 1-Click Rollback / Undo work?

Whenever an organization run executes, Tideway writes a dedicated transaction log in the logs/ directory recording the exact source path, destination path, and timestamp of every file moved.

Clicking Undo in the Web Dashboard or running python main.py --undo-last reads this log and moves every single file back to its precise original location, then deletes any category folders that were left empty.

What happens if a destination file already exists (collision safety)?

Tideway is collision-safe: if a file named report.pdf already exists in the destination folder, Tideway will increment the filename to report_1.pdf, report_2.pdf, etc., guaranteeing zero data loss or accidental overwriting.

What is the difference between Standard Scan and Deep Scan?

Standard Scan: Organizes only the files lying directly inside the top level of the selected folder without traversing nested subdirectories.

Deep Scan: Recursively scans every subfolder and nested folder in the tree, collects scattered files into root category folders, and safely cleans up empty subdirectories left behind.

Background Folder Watchers

How do Background Watchers work?

Background Watchers utilize the Python watchdog library to listen to OS filesystem events. Whenever a new file is created or copied into a monitored folder (like your Downloads directory), the watcher detects it, waits for active writes to finish, and moves it to its appropriate category immediately.

Will running watchers consume high CPU or RAM?

No. Watchers use native kernel file change notifications (ReadDirectoryChangesW on Windows, inotify on Linux, FSEvents on macOS), consuming near-zero CPU while idle and minimal memory (~20–30 MB).

Rules & Customization

How do I add custom file extensions or new categories?

You can configure rules in two ways:

  1. Go to the Category Rules tab in the Web Dashboard (/#tab-rules) to visually edit, add, or delete extensions and categories with live saving.
  2. Directly edit categories.json in the project root. The app automatically reloads modifications on the fly.
What happens to files with unrecognized extensions?

Any file whose extension is not mapped to a specific category is routed to the fallback category (default: Misc). You can customize the name of this fallback folder in the Rules tab.
